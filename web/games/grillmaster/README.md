# Grill Master

Grill Master is an accelerating attention-management game. Each cut progresses from
raw to cooked to burnt on its own timer. Pull cooked meat during the green window;
pulling raw meat or leaving it to char costs one point.

Sessions run from one to three minutes. Completed sessions save accuracy, cooked cuts,
raw pulls, charred cuts, streaks, peak grill load, and cook-time metrics to the shared
local NeuroPractice history.

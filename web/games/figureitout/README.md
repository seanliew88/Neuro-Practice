# Figure It Out

Figure It Out hides a figure face-down. Players recreate its active properties,
receiving only the number of matching and missed properties after each guess. Rounds
start with shape and colour, then unlock pattern, size, and border at each session
quarter.

There is no guess limit. The card flips after an exact match, a user skip, or the
session ending. Sessions run from one to five minutes and save solved, skipped, and
failed rounds alongside guess and property-match metrics locally.

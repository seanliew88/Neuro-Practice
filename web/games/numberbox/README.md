# Number Box

Number Box presents four numbers and a target. Select two current values, then apply
addition, subtraction, multiplication, or division to collapse them into an exact
intermediate value. Three operations consume all four starting numbers without manual
parentheses, and the board can be reset at any point.

Sessions run from one to five minutes. Completed sessions save solved puzzles,
attempts, accuracy, score, skips, resets, streaks, and solve-time metrics to NeuroPractice's
local per-game history.

# Balloon

Balloon is a timed practice game inspired by the Balloon Analogue Risk Task (BART).
Each pump increases unbanked earnings while moving the current balloon closer to its
hidden burst point. Cashing out banks the balloon; bursting loses its earnings.

The session moves through early, rising, and high-stakes phases with increasing pump
rewards and burst penalties. Sessions run from one to five minutes and save detailed
risk, earnings, pump, cash-out, burst, and penalty metrics locally.
